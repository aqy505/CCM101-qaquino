# Mission 1: Welcome to the Cloud

## Mission Overview

This laboratory activity introduces the basic skills and practices needed when working with cloud-based Linux environments. It covers accessing a Linux environment through KillerCoda, exploring the Linux operating system, gathering system information, organizing files and directories, and creating a professional GitHub portfolio. The activity also introduces Markdown documentation and version-controlled work as part of a cloud computing workflow.

## Objectives

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.

## Activities Performed

- Accessed an Ubuntu Linux environment using KillerCoda.
- Explored the Linux terminal and verified that it was functioning properly.
- Created and configured a new Linux user with a home directory, Bash, and sudo access.
- Logged in to the newly created user account.
- Checked the current username, working directory, and hostname.
- Gathered information about the Linux distribution, kernel, CPU, memory, and disk space.
- Created and organized the required files and directories.
- Created a public GitHub repository for the Cloud Computing portfolio.
- Prepared documentation and screenshots as evidence of the completed activities.

## Linux Commands Used

- `whoami` – Displays the current username.
- `pwd` – Displays the current working directory.
- `hostname` – Displays the system hostname.
- `useradd` – Creates a new user account.
- `usermod` – Modifies user account settings.
- `passwd` – Sets or changes a user's password.
- `su` – Switches to another user account.
- `cd` – Changes the current directory.
- `mkdir` – Creates directories.
- `ls` – Lists files and directories.
- `cat` – Displays the contents of a file.
- `uname` – Displays system and kernel information.
- `lscpu` – Displays CPU information.
- `free` – Displays memory information.
- `df` – Displays disk space information.

## Skills Learned

I learned basic skills in Linux navigation, user management, system information gathering, file organization, Markdown documentation, and GitHub repository management. These skills provide a foundation for working with cloud environments and performing basic system administration tasks.
