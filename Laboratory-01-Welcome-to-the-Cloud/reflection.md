Reflection

This laboratory activity gave me a basic introduction to working with a cloud-based Linux environment. Using KillerCoda helped me understand how Linux can be accessed and used in the cloud without having to install it directly on my computer.

During the activity, I learned how to use basic Linux commands to navigate the system, create a new user, and check different system information. I was able to check the Linux distribution, kernel version, CPU, memory, and available disk space. These tasks helped me become more comfortable with using the Linux terminal and understanding the environment I was working with.

Although I already have some experience using GitHub, this activity helped me see how it can be used to organize and document my Cloud Computing laboratory activities. I also already had prior knowledge of Markdown, but this activity added to my understanding of its proper use in structuring and presenting technical information in a clear and organized way. Setting up the repository and arranging the files also helped me understand the importance of keeping technical work properly organized.

Overall, this activity helped me improve my basic skills in Linux, Markdown, and cloud-based environments while also giving me a different way to use GitHub. It gave me a good starting point for the upcoming cloud computing and system administration activities.
