# Microsoft Azure Research 

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides cloud services for computing, storage, networking, databases, security, analytics, artificial intelligence, and application development. Organizations can use Azure to create new cloud applications or move their existing systems and workloads to the cloud.

## Global Infrastructure

Microsoft Azure operates cloud infrastructure across different geographical locations around the world. Its infrastructure is organized into **Regions**, with many regions supporting **Availability Zones**. These locations allow organizations to deploy their applications and resources closer to their customers while improving reliability and availability.

## Cloud Management Console

The **Microsoft Azure Portal** is a web-based management console used to create, configure, manage, and monitor Azure resources. Through the portal, users can manage virtual machines, networks, storage, databases, security settings, subscriptions, costs, and other Azure services using a graphical interface.

## Four (4) Core Services

| Azure Service              | Category            | Description                                                                                                    |
| -------------------------- | ------------------- | -------------------------------------------------------------------------------------------------------------- |
| **Azure Virtual Machines** | Compute             | Provides virtual computers for running applications and different operating systems in the cloud.              |
| **Azure Blob Storage**     | Storage             | Provides object storage for large amounts of unstructured data such as documents, images, videos, and backups. |
| **Azure Virtual Network**  | Networking          | Allows organizations to create private networks and securely connect Azure resources.                          |
| **Microsoft Entra ID**     | Identity & Security | Provides identity and access management for users, applications, and organizational resources.                 |

## Three (3) Advantages

1. **Microsoft Integration** – Azure works well with Microsoft technologies and services commonly used by businesses.
2. **Scalability and Flexibility** – Organizations can adjust their cloud resources according to changing workloads and requirements.
3. **Global Infrastructure** – Azure's worldwide infrastructure allows businesses to deploy applications and services in different geographical locations.

## Typical Enterprise Use Cases

Microsoft Azure can be used by enterprises for:

* Hosting websites and enterprise applications
* Running Windows and Linux virtual machines
* Storing business files and backups
* Creating cloud-based databases
* Developing and testing applications
* Data analytics and artificial intelligence
* Backup and disaster recovery
* Hybrid cloud environments
* Migrating existing company systems to the cloud
