# Cloud Provider Comparison

A comparison of the core infrastructure services offered by three leading public cloud providers. Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). The comparison is based on the official documentation provided by each cloud provider.

## Service Comparison Table

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | EC2 (Elastic Compute Cloud) | Virtual Machines | Compute Engine |
| Storage | S3 (Simple Storage Service) / EBS | Blob Storage / Managed Disks | Cloud Storage / Persistent Disk |
| Networking | VPC (Virtual Private Cloud) | Virtual Network (VNet) | VPC (Virtual Private Cloud) |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID (formerly Azure AD) | Cloud IAM |

## Guide Questions

**1. Which cloud provider offers the broadest range of services?**

AWS. It was the first major cloud platform, so it's had the most time to
build out different services. It also has the largest list of products
compared to Azure and GCP.

**2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products?**

Azure, since it works best with Microsoft stuff like Windows Server,
Active Directory, and Office 365. It would just be easier to set up and
manage if the company already uses Microsoft tools.

**3. Which platform is widely recognized for AI, ML, and Kubernetes services?**

Google Cloud Platform. Google actually created Kubernetes, so GCP has
one of the best managed Kubernetes services (GKE). They're also known
for AI/ML tools like Vertex AI.

**4. What similarities did you observe among the three cloud providers?**

All three basically offer the same things — compute, storage,
networking, IAM — just with different names for each. They're also all
pay-as-you-go and let you scale up or down without buying hardware.
