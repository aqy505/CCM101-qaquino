# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory activity focuses on understanding cloud storage and deploying an object storage server using Docker. MinIO was used to create an S3-compatible storage environment where files can be stored inside buckets. The activity also involved accessing the MinIO Web Console, creating a bucket, and uploading a sample file.

## Objectives

- Understand the differences between Block, File, and Object Storage.
- Learn how Object Storage is used for storing unstructured data such as images and videos.
- Deploy a MinIO Object Storage server using Docker.
- Access the MinIO Web Console through port forwarding.
- Create a storage bucket and upload a file.
- Practice documenting cloud storage operations using Markdown.
- Continue developing a GitHub Cloud Computing portfolio.

## Tools Used

- **KillerCoda Ubuntu Playground** - Used as the Linux environment for running Docker.
- **Docker** - Used to deploy and run the MinIO server as a container.
- **MinIO** - Used as the S3-compatible Object Storage server.
- **MinIO Web Console** - Used to manage buckets and upload files.
- **GitHub** - Used to store and document the laboratory activity.
- **Markdown** - Used to create the technical documentation.

## Skills Learned

- Comparing Block, File, and Object Storage.
- Deploying an Object Storage server using Docker.
- Using Docker environment variables.
- Understanding Docker port mapping.
- Accessing a containerized service through a web interface.
- Creating and managing a storage bucket.
- Uploading objects to cloud storage.
- Using Linux and Docker commands.
- Writing technical documentation using Markdown.
- Organizing laboratory activities in a GitHub repository.
