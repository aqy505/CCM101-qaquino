# Mission Reflection

Out of all the cloud infrastructure components covered in this lab, I
think storage is the most important one. Compute and networking matter
a lot too, but if data isn't saved properly, none of that really
matters in the end. Everything a business relies on customer info,
files, records has to be stored somewhere reliable, so to me storage
feels like the foundation everything else is built on.

This lab also gave me a better appreciation for how much Linux supports
cloud computing behind the scenes. Linux is basically everywhere in this
space because it's free, open-source, and lightweight compared to other
operating systems. Most cloud servers, including the one I used through
KillerCoda, run on Linux since it's flexible and doesn't need a lot of
resources to operate, which makes it cheaper and easier for cloud
providers to scale up or down.

Doing this lab also made me understand why technical documentation
matters so much before actually deploying anything. Documentation makes
sure everyone on a team understands what's being built before it goes
live, and if something breaks later, having clear docs means engineers
don't have to guess what was set up or why. Writing things down also
forces you to actually think through the setup instead of just doing it
blindly, which helps avoid mistakes early on.

In terms of skills, I learned how to check system specs using Linux
commands like `lscpu`, `free -h`, and `df -h`, which I hadn't really
used before this. I also learned how different cloud providers (AWS,
Azure, and GCP) name their services differently even though they
basically offer the same things, and I got a lot more comfortable
writing documentation in Markdown using tables and headers.

Overall, my GitHub portfolio feels more complete now. It has an actual
second lab folder with real documentation and it looks more organized 
and professional. More importantly, it shows a full process from 
investigating a server, to comparing cloud providers, to designing a
simple architecture which is something I can actually show off later on.
