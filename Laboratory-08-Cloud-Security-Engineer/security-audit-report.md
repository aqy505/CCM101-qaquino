# Security Audit Report

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users only the permissions they need to do their tasks. This is important in cloud accounts because it helps prevent unauthorized access to important files, systems, and information.

## 2. Attack Surface

The attack surface refers to all the possible points where an attacker could try to access or affect a virtual machine. Open ports, running services, and weak security settings can increase the attack surface, so unnecessary access should be limited.

## 3. Default Deny Policy

A Default Deny policy blocks incoming traffic unless it is specifically allowed by a firewall rule. This is safer because it limits access to only the services that are needed instead of trying to block every possible attacker one by one.
